# lottery_sb
[misunwen.github.io/lottery_sb](https://misunwen.github.io/lottery_sb/lottery.HTML)
- **加權抽籤**：加權越高，被抽中機率越高（支援小數 1 位）
- **即時機率顯示**：表格顯示每人本輪的入選機率
- **抽籤動畫**：老虎機動畫，可隨時「跳過動畫」（不影響結果）
- **重複抽取**：開啟後逐一抽取，抽過的人自動反白排除，可重置
- **名單儲存**：本機可存 3 組名單，支援儲存／讀取／預覽
- **匯入 CSV**：批次匯入人員（格式：`編號,姓名`，可選第三欄為加權）
- **抽籤歷史**：自動記錄每次結果（低機率中獎會標記）
- **公平性**：使用 `crypto` 真隨機亂數
